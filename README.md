# Lab: Gas Expense Calculator
This lab takes the entered values for trip count and gas costs to print the average gas cost of all trips combined
## How To Run:
1. Open program in your IDE
2. Enter values when prompted
3. View calculated output

## Example Output
How many trips did you make? 3
Enter gas cost for trip 1: 42.50
Enter gas cost for trip 2: 37.80
Enter gas cost for trip 3: 45.20

--- Gas Expense Summary ---
Trip 1: $42.5
Trip 2: $37.8
Trip 3: $45.2
Total spent on gas: $125.5
Average per trip: $41.83
